# Novelty（新鲜感）

Novelty 负责避免 Persona 回复机械重复。当前阶段只作为表达质量约束，不是单独算法模块。

## Current

- 当前没有独立的新鲜感评分、去重缓存或风格轮换器。
- 允许在 prompt 中要求 Companion 避免模板化开场和重复措辞。
- 新鲜感不得优先于准确性、边界感和用户当前意图。

## Later

- 基于近期对话摘要检测重复表达。
- 给 Companion 提供少量风格候选，而不是随机生成。
- 在 Workspace 中展示可审计的“表达风格”配置。

## AI 修改边界

- 可以优化 style-guide 或 prompt，让回复更自然。
- 不可以为了新鲜感编造事实、记忆或用户偏好。
- 不可以把 Novelty 写入 Profile，除非有稳定、可追溯的偏好证据。
- 不可以新增向量库、图数据库或外部服务来解决重复问题。
