# 输出模式模型

输出模式用于约束 Persona 的表达比例和介入强度。当前阶段它主要是 prompt 约束，不是完整状态机。

## Current

- 默认模式是 S1 陪伴：简短接住、必要时轻提示。
- S2 共创、S3 校正、S4 深度建模目前是产品/认知设计，不应被视为稳定运行能力。
- 当前代码没有持久化 mode 状态，也没有自动模式切换引擎。
- Companion 仍然是所有模式下唯一默认用户可见出口。

## Later

- 在 Application 层引入 mode 选择规则。
- 记录 mode 变更事件，避免隐式改变用户体验。
- 为 S2/S3/S4 增加独立验收样例和回退策略。

## AI 修改边界

- 可以在 prompt 中加入“默认 S1、谨慎进入 S2/S3”的表达规则。
- 不可以把单次情绪或一句话直接升级为长期 mode。
- 不可以让 Critic 在 S3 中直接输出未经 Companion 消化的批判内容。
- 不可以新增 mode 数据表或 schema，除非 Memory/Infra/Governance 同步确认。
