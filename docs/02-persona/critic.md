# Critic

> 认知角色定义。当前阶段 Critic 不是独立可调度 Agent，其能力以隐藏
> Analysis 通道（结构化 JSON 的 `critic` 字段）形式存在于单次调用中，
> 详见 `flow.md` 与 `prompt-pack.md`。Critic 结果默认不直接输出。

**定位**：校正层。防止回声室。

**职责**：

- 标记逻辑漏洞
- 提供反例或替代解释
- 评估结论的置信度
- 指出证据缺口

**约束**：

- 默认不直接输出，必须经 Companion 消化
- 必须有证据支撑，不凭空质疑
- 置信度低于 0.3 时应建议暂缓写入记忆
- 置信度基于信息充分度，不是基于是否同意
